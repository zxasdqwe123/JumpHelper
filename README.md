# JumpHelper · 微信跳一跳助手（V2.0 智能版）

专为 **无电脑、无 Root、单台 Android 手机（Android 11–17 / ColorOS 17）** 打造的原生 Kotlin 微信跳一跳辅助工具。

- **最新编译 APK 下载**：前往 [GitHub Releases](https://github.com/zxasdqwe123/JumpHelper/releases/latest) 直接用手机浏览器下载 `JumpHelper-debug.apk` 安装（同时每次构建也会上传到 GitHub Actions Artifacts）。

---

## 核心特性（V2.0.0 全面升级）

1. **V2.0 纯 Kotlin 多线索几何识别引擎（零 OpenCV 依赖）**
   - **物理阴影剥离**：基于跳一跳地面投影的 `~0.70×` 中性等比变暗不变性，彻底剔除绿色圆桌、矮凳、圆柱左下方的投射阴影，不再把落点拽偏。
   - **双拐点独立轮廓拟合（抗高分复杂方块）**：不再假设 `topX == centerX`，而是独立追踪左右外边界拐点并用对称中点定位中心，精准覆盖 **非正方形长凳/书本、魔方多色顶面、薄圆桌、快递箱、高光纯白块、屋顶/瓶盖凸起** 与粉色/暗色变色背景。
   - **白点靶心优先锁死**：精确识别 `#F4F4F4` 椭圆中心靶点并做四向对比度验证，命中直接亚像素锁死，大幅拉高连击加分。
   - **棋子「圆头 + 底座」双锚点 + 贴身掩码**：深色方块不漂移，高分极近距离迷你方块不被误切。
   - **3D 等距反投影距离**：从单轴 `|dx|` 升级为二维 3D 反投影 $d_{\text{eff}} = \sqrt{0.5\Delta x^2 + 1.5\Delta y^2}$（按几何置信度融合），即使上一跳落偏边角，下一跳也能直接拉回中心。

2. **零额外截图 · 无感闭环自校准（开箱即准）**
   - 不增加额外截屏调用、不触发 Android 截图冷却限制：每跳下一格截图时顺手测量新棋子相对当前脚下方块中心的偏心，并结合**方块宽度指纹 + 置信度双护栏**自动识别偏近/偏远，平滑收敛本机专属的 `(满短边系数, 触控固定延迟)`。

3. **极致使用体验升级**
   - **零闪烁智能截屏**：悬浮条停靠在屏幕底部（游戏扫描区外）时截屏不再闪烁隐藏，手感顺滑。
   - **三色置信度准星 + 复杂方块智能护航**：青绿（白点锁死/高把握）、琥珀黄（注意）、红色警报（极端低把握复杂方块自动暂停护航，防止直接摔断高分）。
   - **「🎯 救场」一键单点瞄准**：点开救场自动预锁棋子底座并画出 30° 引导线，你只需**轻点目标方块中心一下**即刻起跳（也可点「重选起点」切换双点）。
   - **清爽折叠悬浮面板 + 节奏档位**：默认隐藏复杂手调按钮（点「调参」随时展开）；支持 **极速 / 均衡(推荐) / 稳健** 三档连跳节奏与长跳自动缓冲；检测到结算页自动静默暂停。

4. **Android 16–17 / ColorOS 17 单机深度适配**
   - 完整保留 **前台 `specialUse` 防杀保活**、**2× sRGB 低内存截屏管线**（单跳工作内存 ~3.5MB）、**截图/手势看门狗** 与 **`ApplicationExitInfo` 系统杀后台诊断**。
   - 内置 Android 13–17「受限设置」一键解锁引导，使用 `TYPE_ACCESSIBILITY_OVERLAY` 免额外悬浮窗权限。

## 手机端安装与启用步骤（Android 13–17 / ColorOS 17）

1. 在手机浏览器打开本仓库的 [Releases 页面](https://github.com/zxasdqwe123/JumpHelper/releases/latest)，下载并安装 `JumpHelper-debug.apk`。
2. 打开 **跳一跳助手**，点击首页 **「1. 打开无障碍服务设置」**，找到 **JumpHelper 跳一跳助手** 并尝试开启（若弹出“受限制的设置”提示，点确定即可触发系统解锁项）。
3. 返回 App 点击 **「2. 允许受限设置（跳转应用信息页）」** → 点击右上角 **「⋮」** → 选择 **「允许受限设置」** 并通过指纹或锁屏密码验证。
4. 再次点击 **「1. 打开无障碍服务设置」** 打开开关，悬浮控制条即默认停靠在屏幕底部零闪烁区。
5. **ColorOS 17 / Android 17 防杀后台必做**：
   - 在 App 首页点击 **「1. 忽略电池优化」**、**「2. 开启通知权限」**，并在 **「3. ColorOS 耗电/后台自启动设置」** 中打开「允许完全后台行为」与「允许自启动」；
   - 在最近任务界面给 **跳一跳助手** 卡片「🔒 锁定」。
6. 点击 **「打开微信」** 进入跳一跳游戏，直接点 `▶ 自动` 即可开跳，前 3~5 跳会自动完成本机闭环校准！
